# Built-in Praxis Authority Model v1 Acceptance

Status: Accepted

Date: 2026-09-15

The architecture owner accepted the exact artifacts:

- ADR-074, `sha256:6b4153fdc6ddc10bddbb0dfdc1f75318ff3f1670e19065e5a91ccfdf19880ea2`
- SPEC-037, `sha256:bfe45bb04e6b5a18477c0597c8c5ae5e86398d39d37e2e789890ea4d4e794aec`

The v1 boundary is the closed installation-root `authority.delegate` edge to
a distinct controller's exact `workplan.accept` authority over a protected
WorkPlan target. Runtime package/provider capabilities remain CapabilityLease
concerns. Historical open-string authority is not reinterpreted.

This acceptance authorizes recording, implementation, and qualification of
the exact v1 semantics. It does not bootstrap authority, create a delegated
generation, approve a WorkPlan, activate packages, or authorize Japetella.
