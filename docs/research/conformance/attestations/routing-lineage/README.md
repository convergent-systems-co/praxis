# routing-lineage attestation series

Attestation records produced on the `redesign/praxis2` lineage (Sep 17,
2026) before it was reconciled onto the canonical lineage. Their version
numbers were minted independently and collide by name with the canonical
series in the parent directory, so they are preserved here unchanged and
distinguishable. The inventory in `internal/conformance/praxis_audit.go`
references the canonical series only.
